## Run Locally

1. Clone this repository:
   ```bash
   git clone https://github.com/Simran-317/my-portfolio.git
   ```
2. Open the project folder.
3. Open `index.html` in your browser.

Make sure `index.html`, `style.css`, and `script.js` remain in the same folder.
